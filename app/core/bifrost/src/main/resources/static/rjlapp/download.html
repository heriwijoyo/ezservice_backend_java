Unduh APK

Panduan Cara Instal:

  1. Unduh APK dengan mengklik tombol "Unduh APK" di atas.
  2. Buka menu Pengaturan pada handphone Android anda.
  3. Skrol ke bawah dan klik pada menu Keamanan atau Privasi (tergantung tipe HP anda).
  4. Ijinkan pilihan Sumber Tidak Dikenal atau Instal aplikasi yg tidak dikenal.
  5. Cari file APK yang telah diunduh menggunakan aplikasi File Manager.
  6. Klik pada file APK tersebut untuk memulai proses instalasi.
  7. Ikuti petunjuk instalasi pada layar HP anda hingga selesai.

Note: Anda dapat mengembalikan pengaturan pilihan "Sumber Tidak Dikenal" setelah proses instalasi berhasil.
